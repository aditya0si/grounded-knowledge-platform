# Data Classification Standard

**Document ID:** `data-classification-standard`  
**Classification:** sec, eng  
**Owner:** Security Engineering

---

## Tiers

Data is classified as Public, Internal, Confidential, or Restricted. Restricted data may be processed only in approved regions.

## Retention by tier

Confidential records must be retained for 10 years before review for deletion.

Restricted records are retained indefinitely unless a valid erasure request is received.
